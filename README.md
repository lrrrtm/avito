# Сервис для автоматического назначения ревьюверов на Pull Request'ы (Тестовое задание в Авито, Осень 2025)

## Запуск
Для запуска нужно использовать docker-compose:

```bash
docker-compose up --build
```

Документация к API (Swagger) будет доступна по адресу `http://localhost:8080/docs`


## Стек
- Python 3.11
- FastAPI
- PostgreSQL
- SQLAlchemy

## Дополнительные требования
- Проведено нагрузочное тестирование, отчёт далее.
- Добавлен эндпоинт `/stats` со статистикой по количеству PR в разрезе пользователей и по количеству пользователей на каждом PR.
- Реализовано интеграционное и E2E тестирование, отчёт далее.
- Добавлен эндпоинт массовой деактивации пользователей в команде (`/team/deactivate`). Операции с БД выполняются пакетно, это позволяет уложиться в 100 мс при обновлении большого количества записей.
- Конфигурация линтёра описана в файле `pyproject.toml`

## Допущения
- При создании команды, если пользователи, передаваемые в теле запроса, уже существуют, то их данные обновляются (имя, флаг активности, команда приписки).
- При переназначении ревьювера, если нет доступных кандидатов (все остальные неактивны или уже назначены), возвращается ошибка `NO_CANDIDATE`.

## Тестирование
Реализованы интеграционные и E2E тесты.

**Интеграционные тесты (`tests/test_integration.py`) проверяют:**
- Полный цикл работы с PR: создание команды, создание PR, назначение ревьюверов, проверка списков ревью, мёрдж PR.
- Логику переназначения ревьювера (reassign).
- Логику массовой деактивации пользователей с автоматическим переназначением их активных PR.
- Работу health-check эндпоинта.

Тесты запускаются внутри контейнера и используют `ASGITransport` для прямого вызова приложения.

**E2E тесты (`tests/test_e2e.py`) проверяют:**
- Доступность API извне.
- Базовые сценарии (создание команды, создание и мёрдж PR) через HTTP запросы к `http://localhost:8080`.

Запуск интеграционного теста:
```bash
docker exec avito-app-1 pytest tests/test_integration.py
```

Запуск E2E теста (приложение должно быть запущено на `http://localhost:8080`):
```bash
docker exec avito-app-1 pytest tests/test_e2e.py
```

## Линтёр
В проекте используется [Ruff](https://docs.astral.sh/ruff/) для линтинга и форматирования кода. Конфигурация находится в файле `pyproject.toml`.

Для запуска линтёра необходимо установить зависимость и, находясь в директории проекта, вызвать проверку:
```bash
pip install ruff==0.1.14
ruff check .
```
